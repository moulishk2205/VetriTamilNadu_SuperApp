# VETRI TAMIL NADU — "One Thread" · final shot plan (v1)

Synthesis of the 4-concept / 3-judge panel. Base: ONE THREAD (96 BPM, 8 bars × 2.5 s, the gold rule as
the film's single line). Grafts: GEOGRAPHY's opening ignition + polygon-hinged MLA ending + ring echo +
scattered→ordered sound logic; UI-DECONSTRUCTION's UI fidelity, Tamil hero type, push-through-arrow,
yellow decision spark.

1. **Product (one sentence):** One citizen identity → 21 state services → one 15-stage workflow → a
   verified certificate in the citizen's Digital Locker, with officers, departments and MLAs seeing the same record.
2. **Problem:** one life event (buying land) = 5 services across 4 departments that must be done in order;
   the citizen is left to work out which office comes first.
3. **Capabilities shown:** (a) Ask Vetri plans the order (deterministic); (b) one workflow carries the
   application to a named officer's approval and a certificate in the Locker; (c) the same record counts
   on the constituency dashboard.
4. **Strongest real screens:** Ask Vetri reply (Tamil headline + 4 chips), EC stepper, acknowledgement
   (APP-2026-EC-44822 + QR), workflow timeline, officer Approve & Issue, Locker (5th card CRT-2026-EC-44822),
   Mylapore Constituency tiles (4,233→4,234 · 3,867→3,868 — verified before/after).
5. **Metaphor:** the app's 3px gold rule is the thread connecting a citizen to the government.
6. **Arc:** COMPLEXITY (0–5) → INTELLIGENCE (5–7.5) → ACTION (7.5–15) → IMPACT (15–20).
